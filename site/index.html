batfiles

A dotfiles manager built around plain files and explicit composition.

Linux and macOS

curl -fsSL https://batfiles.dev/install.sh | sh -s -- clone https://github.com/me/dotfiles

Windows, in PowerShell 7

& ([scriptblock]::Create((irm https://batfiles.dev/install.ps1))) clone https://github.com/me/dotfiles

Without clone and its URL, either one only installs batfiles.
